====================================================
  PERSONA STUDIO - Windows Installation Guide
====================================================

WHAT THIS DOES:
  Real-time face swap for video calls (Zoom, Teams, Discord).
  Your webcam feed is swapped with a face photo you choose.
  100% offline. No cloud, no accounts, no data leaves your PC.

----------------------------------------------------
STEP 1: Install Python (one-time)
----------------------------------------------------
  1. Go to https://python.org/downloads/
  2. Download Python 3.10 or newer
  3. RUN THE INSTALLER
  4. IMPORTANT: Check "Add Python to PATH" at the bottom
  5. Click Install

----------------------------------------------------
STEP 2: Run Persona Studio
----------------------------------------------------
  Double-click:  start.bat

  The first run will install dependencies automatically
  (takes 1-2 minutes, one-time only).

----------------------------------------------------
STEP 3: Use in a video call
----------------------------------------------------
  1. After start.bat is running, open Google Chrome
  2. Go to:  http://localhost:6967/cam
  3. Click "+ Face" button and upload a face photo
  4. Click "Start" to begin face swap
  5. In Zoom/Teams/Discord: Share Screen -> select this tab

----------------------------------------------------
QUICK REFERENCE
----------------------------------------------------
  With a source face:
    start.bat --source C:\Users\You\Pictures\my_face.jpg

  Stop server:
    Press Ctrl+C in the terminal window

  Need help?
    The face photo should be front-facing, well-lit,
    with both eyes visible.

----------------------------------------------------
NO PHONE NEEDED - Everything runs on your laptop.
NO INTERNET NEEDED - Works fully offline after install.
----------------------------------------------------
